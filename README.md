🔌 RESISTOR CALCULATOR

A Python-Based Electrical Engineering Calculation Tool

📌 Project Overview

The Resistor Calculator is a Python-based application designed to simplify resistor calculations in electrical and electronic engineering.

The application allows users to enter resistor values and calculate equivalent resistance, making basic electrical calculations easier, faster and more accurate.

🎯 Project Objectives

* Simplify resistor calculations using Python.
* Calculate equivalent resistance in electrical circuits.
* Reduce errors associated with manual calculations.
* Demonstrate the practical application of programming in Mechatronics Engineering.
* Improve understanding of series and parallel resistor connections.

⚙️ Key Features

* User-friendly input system.
* Accepts multiple resistor values.
* Calculates total resistance.
* Supports series resistor calculations.
* Supports parallel resistor calculations.
* Displays calculation results.

🛠️ Technologies Used

* Programming Language: Python 3
* Code Editor: GitHub
* Testing Platform: Programiz Online Python Compiler
* Version Control: Git and GitHub

📐 Electrical Principles

The project applies the following electrical formulas:

1. Series Resistance

The total resistance of resistors connected in series is:

Rtotal = R1 + R2 + R3 + ...

2. Parallel Resistance

The total resistance of resistors connected in parallel is:

1/Rtotal = 1/R1 + 1/R2 + 1/R3 + ...

🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open resistor_calculator.py using Python.
4. Run the program.
5. Enter the number of resistors requested.
6. Enter the resistance values.
7. View the calculated results.
